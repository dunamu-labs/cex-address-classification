# Proof-of-Reserves Sources

The CEX labels in this study come directly from Proof-of-Reserves disclosures published
by each exchange, not from third-party attribution services. This page lists the PoR page
or address list used for each of the 15 exchanges in the dataset (as of May 2026, the
collection cutoff described in the paper). Exchange formats vary -- some publish address
lists with signed ownership proofs, others publish audit reports or balance dashboards --
so treat these as pointers to each exchange's own disclosure, not a uniform data format.

## Note on stability

PoR pages are maintained by the exchanges themselves and change over time -- disclosure
formats get redesigned, address lists get rotated, and some pages require the exchange's
app or a signed-in session to view. The links above reflect what we used as of the paper's
data collection cutoff; the addresses actually used to build the dataset are fixed, but a
link going stale later doesn't mean the underlying label was.
